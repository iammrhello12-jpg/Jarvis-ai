# JARVIS AI

An intelligent AI assistant that helps you with all aspects of your life. Built with Next.js and powered by advanced language models.

## Features

- Real-time AI chat interface
- Streaming responses for instant feedback
- Beautiful, responsive dark-themed UI
- Powered by Claude AI

## Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, or pnpm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to start chatting with JARVIS.

### Production Build

```bash
npm run build
npm run start
```

## Deployment

This project is ready to deploy on [Vercel](https://vercel.com). Simply connect your GitHub repository and deploy.

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **AI**: Vercel AI SDK 6 with Claude
- **Styling**: Tailwind CSS 4
- **Language**: TypeScript
